# 里程碑规则（2026-10-18 起）

唯一实现：scripts/check_milestones.py，生产构建由 reconcile_stats.py 调用并校验。

- 个人进球/助攻按具体战况明确记名的事件累计。花名册球员临时在对方分组参赛，仍计个人数据；球队对外胜负另用球队归属规则，不能混用。
- 本队侧明确记名的历史球员同样保留；未知对手、乌龙、无法归属的进球不计个人里程碑。
- 出勤按花名册已到日期列累计；排除未来记录，同日多场合并，按首次跨越整百门槛给出日期。
- 汇总用于完整性检查，不能补造日期。若汇总已达整百而逐场未达，生产构建明确报出球员/范围/指标/门槛并停止，必须核查原始事件，不能删检查来通过发布。
- 姜珂生涯 1000 球：2026-10-17。此前漏掉的五球为 2023-05-27 红白队四球及 2025-11-01 临时在另一分组的一球。
- 不再执行旧的“汇总和明细完全相等才显示全部日期”规则，也不允许把缺失里程碑当作正常发布结果。
