# 里程碑来源与回归约束

进球/助攻由 stats_model.parse_matches 解析具体战况 CSV，再由 check_milestones.compute_milestones 按日期累计。出勤由花名册日期列累计。构建先 reconcile 再运行全部 test_*.py，检查失败即停止发布。

- 进球固定为 CSV 第 5/9 列、助攻第 6/10 列（从 1 起算），不能根据球场列是否有人名猜测左移。
- 内部友谊赛双方均属于俱乐部；红白队也是内部队名。个人里程碑按花名册球员身份归属，即使临时代表另一分组也计入，不能套用球队战绩过滤。
- 同一行同时记录比分和首个进球时，保留首个进球及助攻。
- 明细与表头日期不同，仅在显式比赛 ID 一致时归入该场表头日期，并保留问题提示；不能跨错误日期块或不同 ID 拼接。
- 所有花名册汇总已达到的整百门槛均须有里程碑；不一致必须查原始行，不能直接删除达成记录或用汇总差额虚构日期。

2026-10-17 回归锚点：姜珂 2026 赛季第 200 球为 2026-10-15；2021 赛季第 100 球为 2021-12-29；潘磊生涯第 400 球为 2026-09-26。完整测试覆盖所有球员/赛季/指标整百门槛与首次跨越日期。

现行完整规则以 milestone-consistency.md 为准，更新和发布使用 sync-workflow.md。
