# 球队网站统计修复与 UI 方案（2026-10-14）

## 本次已落实

- 成立年份统一为 2020，数据统计起于 2021；此前缺失不补估。
- 比赛日、个人出勤、出勤率、评分及资格门槛统一按花名册已到日期列计算。未来预填出勤不计入。生涯评分按逐日积分计算，避免原表团队总成绩漏算 2026 年。
- 榜单涵盖全部有成绩的档案；保留 28 位已不在当前花名册中的历史档案并标注。
- 生涯、赛季、月度、单场纪录重新计算。对外战绩仅计外部两队友谊赛，从本队视角计算，空比分不当成零或平局。
- 战报格式统一解析；同人进球助攻的异常助攻隔离；乌龙与无法归属进球不记个人。比分与个人明细分别保留，不强行凑齐。
- 黄金搭档、球员配合、连续纪录和同赛果组合使用同一份已校验数据。同赛果不等于同队，页面注明估算限制。
- 10 项赛季纪录的 Top20 跳转、图片尺寸、手机布局、全局搜索、数据中心入口修复。球员照片按姓名绑定。
- 趋势竞速与里程碑估算明确标注推算性质，移除未经证实的“误差约 ±2 场”。
- 构建前必做统一统计及一致性校验；每日发布包含对应源码与样式，避免源码和线上产物分离。

## 当前统计快照

球队 518 个比赛日；2026 年 76 个。花名册最后已到比赛日期为 2026-10-13。
战报日期与花名册日期不完全相同，因此趋势图的采样日期数不等于球队比赛日数。

## 保留的原始数据问题

- 日期 `2504016`、`2504023`、`2508027` 格式无效。相关三场战报已隔离，未猜测日期；修正 CSV 后下一次构建会自动恢复统计。
- 生涯与赛季汇总的原始差额：鲍梁剑出场 -4、吴能出场 +1、老池进球 -1／助攻 -1。出勤已按日期列重算，进球和助攻不擅自改写。
- 缺失比分、比分与个人进球明细不相等的情况保留为待核对；不能仅据差额断言错账，可能为乌龙或录像缺失。
- 进球和助攻采用花名册汇总；逐场资料不足时，不制造看似精确的历史走势或达成日期。

完整行号与差异见同目录输出的 data-quality.json（本地审计文件）。

## UI 优化方案

1. 首页优先展示最近比赛、当季三项榜单和队史摘要；趋势图、搭档分析及详细历史下沉到数据中心，减少长页面滚动。
2. 所有统计页保留统一赛季切换与口径说明；明确区分“球队比赛日”“战报对局”“个人出勤”。
3. 移动端后续采用固定的首页／赛程／榜单／球员／更多导航；本次先修复导航可横向滚动和资料卡布局。
4. 榜单统一紧凑行高、固定头像、右对齐数值、并列名次规则；缺失数据统一显示“待补录”或“—”。
5. 后续为球员、赛季和纪录榜提供独立 URL，支持分享、刷新与浏览器返回。当前本次只修复数据中心入口，不扩展完整路由系统。

## 验证

5 项 Python 回归测试通过，涵盖空比分、双方视角、赛事范围、未来日期、日期格式异常隔离、全量数据一致性及重复构建稳定性。
实浏览器检查 10 个 Top20（各 20 行）、36×36 头像、390px 手机布局、子页面搜索弹窗，以及球员／竞速／对比／出勤／阵容页面，无运行错误。
